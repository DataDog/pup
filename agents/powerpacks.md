# Powerpacks Agent

The typed pup CLI does not currently expose Powerpack commands. Do not suggest a `powerpacks` command group or claim to create, list, update, or delete Powerpacks through pup. Use the Datadog UI or the Powerpacks API documentation for those operations.

For dashboard operations that pup does support, see the dashboard commands; dashboards are not a replacement for reusable Powerpacks.
