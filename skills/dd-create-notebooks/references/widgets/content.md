# Content and action widgets

Choose from user intent:

- display an image: `image`
- embed external web content: `iframe`
- run an automation: `run_workflow`

After choosing one type, read its exact reference from
[the widget type index](../widget-types.md).

These are configuration or action widgets. Do not add telemetry `requests` or
analysis cells unless the selected type reference explicitly requires them. Do not
invent image URLs, iframe URLs, or workflow IDs.
